Autonomous Root Tip Inoculation Pipeline

NPEC, via BUas · Individual project · Nov 2025 – Mar 2026

An end-to-end system for NPEC (Netherlands Plant Eco-phenotyping Centre) that finds plant root tips in petri dish images and moves the pipette of a simulated Opentrons OT-2 liquid-handling robot onto each one to inoculate it. A U-Net segments the roots, skeletonization and shortest-path tracing locate the tip of each main root, and a coordinate transform maps it into the robot’s workspace. I compared a PPO reinforcement learning agent with PID control on the same targets: PID was about 8× more accurate and 1.8× faster, so it went into the final pipeline. The system reached 96% end-to-end success with sub-millimeter precision (0.132 mm mean positioning error against a 1 mm requirement), and the same root detection pipeline ranked 8th, in the top 10%, of the associated Kaggle competition.

Plant Phenotyping CV Platform

NPEC, via BUas · Group project · May – Jun 2026

A deployment and MLOps platform for NPEC’s plant phenotyping computer vision models, built as a team. A CI/CD pipeline in GitHub Actions publishes one Docker image to GitHub Container Registry, and that same image runs unmodified on a local machine, on an on-premise server through Portainer, and on Azure Container Apps, with environment variables switching the storage and tracking backends. The platform closes the loop on model quality: user feedback triggers scheduled Airflow retraining, every candidate is evaluated and tracked in MLflow, and a new model is promoted automatically only when it beats the current champion on holdout F1.

  • Portainer
  • Azure Container Apps

Ukrainian Video Emotion Classification

Content Intelligence Agency, via BUas · Group project · Sep – Nov 2025

An end-to-end pipeline for the Content Intelligence Agency (CIA) that tags emotions in Ukrainian-language video. Whisper transcribes the audio, an optional step translates it, and a fine-tuned Ukrainian RoBERTa transformer classifies each segment into one of 7 emotions. Ukrainian is a low-resource language with little labelled data, so we generated synthetic training examples with a local LLM. The classifier reached 78% accuracy, and the project is documented with model cards and privacy and sustainability reporting.

  • RoBERTa
  • HuggingFace Transformers

FingerSpell: Dutch Sign Language Recognition

BUas · Group project · Jan – Feb 2026

A real-time webcam app that teaches and quizzes beginners on the NGT (Dutch Sign Language) finger alphabet, built with two teammates in a 2-week sprint. MediaPipe extracts hand landmarks from every frame. Our first Random Forest handled static hand shapes well, and a CNN reached 99% accuracy but missed the letters that involve movement because it only saw single frames. The final version measures how the landmarks move over a 5-frame window to decide whether a sign is static or dynamic, then routes it to one of two Random Forests, reaching near-100% accuracy across the full alphabet. Users can also collect their own data and train models for other one-handed alphabets.

IKEA PIN Terminal Deployment Analysis

IKEA, via BUas · 2-week data analytics challenge

IKEA wanted to know whether the deployment logs of its in-store PIN terminals could reveal terminals compromised by card skimming, using only serial number, date, location and employee. I built a six-page Power BI dashboard covering employee patterns, terminal reuse across locations, logging delays and compliance with IKEA’s twice-weekly check policy. The clearest pattern was a systematic rotation of two terminals at the same cluster of locations (Eco 2 to Eco 12). The data also showed far more multi-location terminals than the client’s fact sheet listed, and only 4 of 59 locations met the twice-weekly check requirement. The dataset is confidential, so the repository shows the dashboard screenshots and findings only.
